# Approximate U.S. troop levels in Afghanistan, FY2018 to FY2020

The Pentagon stopped publishing troop numbers for Afghanistan, Iraq and Syria in late 2017 (CRS R44116, p. 3). This file gives approximate quarterly levels built from the official figures quoted in the versions of CRS report R45122, *Afghanistan: Background and U.S. Policy: In Brief*, downloaded from EveryCRSReport.com on 29 October 2026. Each row states its basis. The low and high columns bracket the quoted figures; where a quarter spans a change, the central value is a simple midpoint.

These values are used only in the separate FY2018-FY2020 extension, never in the main tests. FY2021 is not given, because troop levels changed within months during the withdrawal.
